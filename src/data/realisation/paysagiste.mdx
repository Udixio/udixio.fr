## Projet
Ce template est une démonstration de ce que Netsimpler rend possible pour un secteur spécifique : le paysagisme. Il est entièrement personnalisable en temps réel via un éditeur de variables — couleurs, textes, coordonnées — sans toucher au code.

Conçu pour présenter les services, les réalisations et les coordonnées d'un paysagiste, il illustre notre approche : un design professionnel, livrable rapidement et adaptable sans dépendance technique.
