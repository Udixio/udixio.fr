## Notre approche

Un portfolio de développeur ne peut pas se permettre d'être lent ou générique. Chaque choix technique est en lui-même un argument de vente : la vitesse de chargement, la qualité du code généré, la fluidité des animations.

Nous avons conçu ce portfolio en mode production : architecture Astro pour la génération statique, React pour les composants interactifs, et Udixio UI pour la cohérence visuelle. Le résultat final affiche des scores Lighthouse proches du maximum sur tous les critères, une démonstration concrète de ce que ce développeur peut livrer à ses clients.

### Un outil de conversion, pas juste une vitrine

Le portfolio est structuré pour convertir des visiteurs en prospects. Les projets sont mis en avant avec leurs résultats chiffrés, le processus de travail est explicité, et le formulaire de contact est directement accessible depuis chaque section. Le site a contribué à décrocher plusieurs missions freelance dans les semaines suivant sa mise en ligne.
