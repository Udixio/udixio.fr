        ## Projet
        Udixio UI est notre bibliothèque interne de composants, utilisée sur l’ensemble de nos projets full code. Elle est une adaptation de Material 3 en **React** et **Tailwind CSS**, enrichie pour nos besoins : animations intégrées via **Motion**, gestion du thème clair/sombre, typographie cohérente.

        Elle est devenue un véritable écosystème : chaque nouveau projet bénéficie d’une base solide, cohérente visuellement, et facile à faire évoluer.
